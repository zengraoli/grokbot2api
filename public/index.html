接入文档

将 Grok Bot 接入支持自定义 OpenAI 接口的客户端，例如 Cherry Studio、Chatbox、DeepSeek Harness。管理接口仅监听本机，请勿暴露到公网。

客户端接入参数

在客户端的「自定义 Provider / 模型服务」设置中填入以下参数。

API 地址（Base URL）
需要完整端点的客户端填写
API Key
sk-none（任意值）
默认未启用鉴权。开启方式：start.bat 中 set GROKBOT_API_KEY=你的key
API 协议
OpenAI Chat Completions
标准 SSE 流式（stream:true），长任务含 keepalive 心跳。
模型 ID
grok-bot ｜ grok-bot-new
grok-bot：账号默认 bot，带跨请求记忆。 grok-bot-new：每请求全新独立对话、无记忆，推荐接入客户端使用。

项目数值说明

          
问答延迟~15s简单问答端到端耗时；流式 0 秒响应头 + 心跳。

          
生成类任务30~130s写 HTML / 画图等 agent 任务；完成信号（附件/收尾措辞/问句/拒绝）自动收尾。

          
文件产物✅ 自动落盘bot 生成的 HTML / 图片等附件存入 files/，回复含本地路径 + 在线预览链接（HTML 渲染动画、图片/音频/视频直接播放）。上限 5MB。

          
图片输入✅ 多模态OpenAI content 数组格式（image_url，data URI 或 http 链接），图片自动上传 bot 沙箱。

          
视频生成❌ 不支持Grok Bot 客户端无视频生成通道。

          
工具调用（tools）❌ 不透传bot 自带工具（联网、文件、画图）；客户端 tools 参数不透传。

          
并发排队单账号串行（忙时排队 ≤120s）；多账号自动轮转并发。

        

      


      

        

          
协议与管理端点
支持的 API 端点。管理接口无鉴权、仅监听 127.0.0.1。

        
方法路径说明

          
POST/v1/chat/completions对话端点，支持流式与多模态。

          
GET/v1/models模型列表（grok-bot / grok-bot-new）。

          
GET/files/<name>附件预览/下载，按扩展名设置 Content-Type。

          
GET/admin/status账号池状态。

          
POST/admin/refresh-all强制刷新全部账号 token。

          
POST/admin/harvest收割本机 Grok Bot 登录凭证并加入池。

        

        
多轮任务：会话历史含任务词（生成/创建/画图/修改等）时，后续短确认消息（"对，补全即可"）自动延续任务等待档，不会被提前截断；bot 拒绝类回复 4 秒内快速返回。
